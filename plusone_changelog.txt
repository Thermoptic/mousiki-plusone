==============================================================================
  MOUSIKI PLUSONE - CHANGELOG
==============================================================================

  Newest changes first. Every entry is grouped by area.
  Key names: SHIFT+ARROW_KEY_UP is how config.txt writes Shift + Up arrow.


==============================================================================
  2026-10-25
==============================================================================


  KEYS: PLAYBACK
  ------------------------------------------------------------------------

  New default keys (Settings > REFERENCE > Playback). All of them can be
  rebound as before.

      Action                 New key                   Was
      ---------------------  ------------------------  ---
      Toggle Play / Pause    SPACE                     p
      Volume Up              SHIFT+ARROW_KEY_UP        +
      Volume Down            SHIFT+ARROW_KEY_DOWN      -
      Next Track             SHIFT+ARROW_KEY_RIGHT     n
      Prev Track             SHIFT+ARROW_KEY_LEFT      b

  * Shift + arrow combinations can now be bound: press the combination in
    a key field, or type for example SHIFT+UP.
  * Where a shifted arrow is not bound to anything it still acts as the
    plain arrow. The big list and queue overlays keep SHIFT+Up / Down for
    paging.
  * Radio Player: SHIFT+Up / Down changes the volume and SHIFT+Right /
    Left tunes the next / previous channel, like in the music player. The
    preset banks moved from SHIFT+Left / Right to ALT+Left / Right.


  KEYS: NAVIGATION
  ------------------------------------------------------------------------

  New keys under Settings > REFERENCE > Navigation & View (also listed in
  the cheat sheet):

      Action                 Key       What it does
      ---------------------  --------  ----------------------------------
      Fast Navigate Up       PgUp      jump 10 rows up
      Fast Navigate Down     PgDn      jump 10 rows down
      Navigate Top           Home      jump to the first row
      Navigate Bottom        End       jump to the last row

  * They work in the track list and in the queue.
  * They can be rebound (names PGUP / PGDN / HOME / END) and are stored in
    config.txt as HKeyNavigateFastUp, HKeyNavigateFastDown,
    HKeyNavigateTop and HKeyNavigateBottom.

  ESC twice in a row (within 0.8 s) in the main view quits the program.
  The first ESC still goes back to the home view.


  PLAY MODE BOX
  ------------------------------------------------------------------------

  The box next to the search bar now shows the play mode as a word instead
  of one letter: LIST, REPEAT, SHUFFLE, STOP or QUEUE (queue then stop).
  M still steps through the modes. The mode is saved at once and is back
  the next time Mousiki starts.

  Next Track follows the play mode: with SHUFFLE on it jumps to a random
  track instead of the next one in the list. The queue still plays in
  order.


  FOLDERS PANE (Music Player)
  ------------------------------------------------------------------------

  F6 swaps the QUEUE pane for a FOLDERS pane, F7 brings the queue back. The
  last choice is remembered (plusone_state.txt next to config.txt).

  The FOLDERS pane is a small file explorer over the local music paths
  (Settings > PATHS > Local Path):

  * Only folders with music files in them or below them are listed, with
    the number of files in each.
  * At the top level an "All" row comes first. It is not a folder: ENTER on
    it lists every track of all the paths in the LOCAL AUDIO FILES pane. It
    is only there at the top; inside a folder it is gone.
  * ENTER on a folder lists the music files lying directly in it in the
    LOCAL AUDIO FILES pane. If the folder holds more folders, the pane goes
    into it and shows those instead (a ">" marks such a folder).
  * BACKSPACE goes one step back; at the top level the paths themselves
    are shown.
  * TAB moves the keys between the track list and the FOLDERS pane. Up,
    Down, PgUp, PgDn, Home and End work as in the lists.


  MODES AND SCREENS
  ------------------------------------------------------------------------

  F1 / F2 / F3 jump straight to the Music Player / Radio Player / Audio
  Book Player. A mode that is switched off under Settings > ON/OFF > MODES
  is skipped with a short note.

  F4 opens the help wizard and F5 opens the settings.

  A key legend now fills the bottom row of the screen:

      F1 music   F2 radio   F3 books   F4 wizard   F5 settings
      F6 folders   F7 queue   ESC quit

  * It is drawn in the colours of the player and the mode you are in is
    highlighted.
  * It is shown in the Music Player, the Audio Book Player and the Radio
    Player. In the radio the station lists give up one row for it.
  * F6 / F7 (folders / queue) only exist in the Music Player.
  * Hold F12 ("F12 controls" in the right corner) and the legend shows the
    playback keys while the key is down: SPACE play, S+left prev track,
    S+right next track, S+up volume up, S+down volume down, M mode,
    S+T sort. Their key boxes use another theme colour than the usual
    ones, and the F12 box itself a third one, so it is clear that other
    keys are showing (colours the theme gives the same value are skipped).
    Let go and the normal legend is back. (Windows only; it is a hint
    about the default keys.)
  * Started with mousiki.cmd or lala.cmd (not mousiki-wt.cmd) the legend
    names the keys after F12 (F12+Up, F12+Left, ...) so they are unique.
  * F12 held down also works as Shift: F12 + Up / Down for volume, F12 +
    Left / Right for previous / next track, F12 + T for sort, and so on.


  WINDOW AND LAUNCHERS
  ------------------------------------------------------------------------

  Portable folder "Mousiki-Plus" with the three launchers mousiki.cmd,
  mousiki-wt.cmd and lala.cmd.

  mousiki-wt.cmd opens Windows Terminal in a roughly square window
  (100 x 48 characters by default).

  The window size is remembered. When Mousiki quits it saves the size of
  the terminal window to window_size.txt next to the launchers, and
  mousiki-wt.cmd opens the next window in that size.

  * Maximized and full screen are remembered too (window_state.txt): if
    Mousiki was closed maximized or in full screen it starts that way. The
    normal size from before is kept, so leaving maximized brings it back.
  * Closing the window with the X button does not save the size; quit
    with the keys.

  mousiki.cmd and lala.cmd in the old console window (cmd.exe): that window
  has no font with the Braille characters, so the disk and the visualizers
  showed up as empty boxes. Mousiki now notices it and draws block
  characters instead (half blocks, full blocks and shades; partly filled
  cells become light / medium / dark shades so edges fade out). It is coarser
  than Braille but keeps the shapes. Windows Terminal (mousiki-wt.cmd), VS
  Code and ConEmu are not affected and keep the Braille look.
  Set MOUSIKI_BLOCKS=1 to force the blocks, MOUSIKI_BLOCKS=0 to force
  Braille.

  The screen now uses the full width of wide windows. The layout used to
  stop at 200 columns and leave an empty strip on the right; it now goes
  up to 400 columns in all three players.
